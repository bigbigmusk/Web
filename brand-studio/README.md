# Brand Studio — 参考灵感 → 原创品牌 VI 与印刷物生成器

一个**零依赖**的纯前端工具：上传参考品牌提取**风格方向**，输入新品牌特点，一键生成
**原创品牌 VI**（色板 / 字体 / Logo 锁版 / 品牌故事）、**商品与 AI 模特出图提示词包**，
并导出**印刷级 PDF**（含 3mm 出血 + 裁切标记 + CMYK 值），用于**电商**与**线下实体店落地**，
可直接发给打印商。

> ⚠️ **合规边界**：参考品牌仅用于提取色彩 / 气质 / 版式语言。本工具生成全新原创品牌，
> **不复制**他人商标、Logo 或可识别标识。请勿用于仿冒。

## 功能
- **风格提取** — 上传参考图，自动从图像中提取主色调作为配色种子。
- **品牌 VI**
  - 色板：主色 / 辅助色 / 点缀色 / 深底 / 浅底，每色附 **HEX + CMYK**。
  - 字体搭配：按品牌个性自动配对（Google Fonts）。
  - Logo 锁版：浅底版 + 深底版（内联 SVG，矢量无损）。
  - 品牌故事 + 语气关键词。
- **出图提示词包** — 8 组面向任意文生图工具（Midjourney / SD / Flux / DALL·E）的提示词：
  商品主图 / 场景 / 微距 / AI 模特棚拍 / AI 模特生活方式 / 包装 3D / 门店 KV / 横版 Banner。
  每组含画幅比例、负面提示与**商标合规守则**。
- **印刷版式（印刷级）** — 每页按真实毫米尺寸输出：
  品牌规范 A4 · 门店海报 A3 · 易拉宝 600×1600 · 手提袋 · 吊牌 · 名片 · 不干胶贴。
  含 3mm 出血、四角裁切标记、安全区与 300dpi 像素建议。

## 使用
直接打开 `index.html`，或本地起服务：
```bash
python3 -m http.server 8000   # → http://localhost:8000
```
1. 左侧填写参考品牌（可选）+ 新品牌特点 → **生成**。
2. 在「品牌 VI / 提示词包 / 印刷版式」三个标签查看。
3. 顶部 **导出印刷级 PDF**：浏览器打印对话框中选「另存为 PDF」，
   **务必勾选「背景图形 / Background graphics」**，纸张选「按来源尺寸 / 实际大小」，
   缩放 100%。每个版式输出为独立一页的真实尺寸 PDF，可直接发印。
4. 也可 **导出品牌包 JSON** 与 **导出提示词 .txt** 交接给设计/供应链。

## 发给打印商前
- PDF 已含出血与裁切线；如印厂要求 **PDF/X-1a / 真 CMYK / 字体外框化**，
  用 Acrobat / InDesign 做一次预检转换即可（本工具按屏幕 RGB→CMYK 数值标注，
  方便印厂校色对位）。
- 易拉宝 600×1600mm 为大幅面，部分浏览器打印对话框需选「自定义尺寸」或保持「实际大小」。

## 技术
纯 HTML + CSS + 原生 JS，无构建步骤、无第三方库。可托管在任意静态主机
（Cloudflare Pages / Netlify / Vercel / GitHub Pages）。所有版式均以 `mm` 排版，
通过 CSS 命名分页 `@page` 为每个版式输出对应纸张尺寸。
