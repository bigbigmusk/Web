# LinkedIn 账号托管系统 — Concord Trade

围绕网站定位（中国应急与工业项目物资供应：PPE、排水防洪、临时电力照明、水务设备）
运营 LinkedIn，目标受众为海外 B2B 买家：采购经理、工程承包商、应急管理机构、NGO。

## 组成

| 文件 | 作用 |
|---|---|
| `content-calendar.json` | 4 周 × 每周 3 篇 = 12 篇待发帖子队列（英文），含发帖规则 |
| `comment-playbook.md` | 互动评论剧本（LinkedIn API 不支持自动评论，人工每天 15 分钟） |

## 内容支柱

1. **行业洞察**（约 60%）：应急采购方法论、供应商验证、PPE 合规标准、汛期备货窗口、紧急货运策略、整合采购
2. **案例走查**（约 20%）：以"流程走查"形式展示典型订单如何执行 —— 不虚构客户名称和成交数字；拿到真实项目数据后可替换为真实案例
3. **公司/服务**（约 20%）：定位、六步工作流、RFQ 指南，均带官网链接引流

## 自动发帖机制

- 通道：Zapier LinkedIn 集成（`share` 动作 = 个人主页发帖；`create_company_update` = 公司主页，需页面管理员权限）
- 节奏：**周一 / 周三 / 周五 13:00 UTC**（≈ 北京时间 21:00，欧洲下午 + 美东上午的活跃窗口）
- 定时任务每次触发时：读取 `content-calendar.json`，取第一条 `status: "queued"` 的帖子发布，
  成功后改为 `posted` 并回写提交，保证不重复发帖
- **前提**：需先在 Zapier 完成一次 LinkedIn 账号授权（授权链接见会话消息）。授权前定时任务会静默跳过，不会发出任何内容

## 维护

- 改帖子：直接编辑 `content-calendar.json` 中对应条目的 `text`（注意正文避免使用半角括号，LinkedIn API 将其视为保留字符）
- 加帖子：往 `posts` 数组末尾追加同结构对象，`status` 设为 `queued`
- 暂停：把定时任务（Routine）禁用即可
